# 目盛りのずれ予測シミュレータ「1次関数とみなせる？」

中学2年 数学（東京書籍「新編 新しい数学2」第3章4節 1次関数の利用 p.85／第16時）の
**1次関数とみなしてよい変域**を体験するための自作ツールです。単一の `index.html` だけで動きます。
数値はすべて授業用に作った**模式データ**で、実際の観測データではありません。
縦軸の量は「目盛りのずれ」、予測と本当の値の差の大きさは「はずれ」と呼んでいます。

## 中身（2つのタブ）
1. **① 2点から予測しよう** … 目盛り合わせで測った2点 A・B（初期 A(2, 3)、B(10, 7)）を
   スライダーやドラッグで動かすと、2点を通る直線の式（変化の割合と b の求め方つき）と、
   選んだ時刻の予測値が表示される。〔展開：ステップ2・3〕
   - **本当のグラフ**（特別な点検の日に細かく測った記録という設定）
     (a) ほぼ直線／(b) 途中で段差（7時ごろ冷凍機の運転が切り替わったメモ）／(c) 外側で曲がる を重ねると、
     本当の値・はずれ・判定（はずれ0.5以内か）が出る。
   - **はずれ0.5の帯** を表示して、1次関数とみなしてよい変域を読み取れる。
   - 「式を見る」ボタンは最初は隠してあり、ワークシートで計算してから確かめる。
2. **② 1次関数とみなせる？** … 測る間かく（8・4・2時間おき）と予測のしかた
   （10時までの測定だけで予測〔最初の画面、ステップ3と同じ〕／18時の測定も使って結ぶ／変域を分ける）を切り替え、
   はずれが0.5をこえる時間と、みなしてよい変域を調べる。〔展開：ステップ4〕

## 使い方
- ファイルをブラウザで開くだけ（外部ライブラリなし。オフラインでも動きます）。
- タブレット配布時は、GitHub Pages に置いて **QRコード** で配ります。

### GitHub Pages で公開する手順（例）
1. リポジトリ `math-pedagogy-1` の中に `linear/` フォルダを作る。
2. この `index.html` を `linear/index.html` として置き、push する（※授業者本人が行う）。
3. Settings → Pages → Branch を `main` / `root` にして保存。
4. 数分後に `https://momohayashi304.github.io/math-pedagogy-1/linear/` で公開。
5. QRコードは `_共通/tools/make_qr.py` で作成済み（原本は題目フォルダの `画像素材/qr_simulator.png`。資料で使うものは `完成版/画像素材/qr_simulator.png` にコピー）。

## 授業での位置づけ（40分）
- 導入(6分)：使わない（スライドで冷蔵庫の例と研究の話）。
- 展開(26分)：ステップ1は紙で計算。ステップ2の冒頭にQRで開き、タブ①で本当のグラフを重ねてはずれを表に記入 → はずれ0.5の帯で変域を考える。
  タブ②で、10時までの測定だけ（ステップ3と同じ）→ 変域を分ける → 18時の測定も使って結ぶ・測る間かくを短くする、を確かめる（教師が電子黒板で示し、生徒も操作）。
- まとめ(8分)：家庭でQRから再確認。

## 家庭で試す用
- (c) で「10時までの測定だけで予測」にして、測る間かくを8時間→4時間にすると、延ばす時間が短くなってはずれが小さくなる（授業では扱わない）。

## 調整メモ
- 本当のグラフの式は `index.html` 内の `truthA` `truthB` `truthC`、判定の基準は `TOL`（0.5）、許容誤差は `EPS`（1e-9）。
- 初期の点は `INIT = {A:[2,3], B:[10,7], t:6}`。
- 操作用の関数：`setTab` `setA` `setB` `setT` `setTruth` `setBand` `setFormula` `setTruth2` `setEvery` `setMode2`。
- 「変域を分ける」のはずれは `errSplitAt`（7時に予測値が2つある）。共通の `errAt` を使うと7時で2と出る。
- 模式データの元：`../data/linear_params.json`（`_生成スクリプト/01_模式データの生成.py`）。期待値は `../data/linear_design_numbers.json`（`02_設計用の数値の検算.py`）。
- 「最大のはずれ」は (b) で回数を増やしても単調に減らない（1.25→1.5→1.0）ので、主な表示は「はずれが0.5をこえる時間」にしている。
- 画面の数値と期待値の照合・画面写真（`画像素材/sim_tab1.png`・`sim_tab2.png`）の撮り直しは `_生成スクリプト/シミュレータ_検算と撮影.py`。
