# 光子すごろくシミュレータ「光子すごろく」

中学1年 数学（東京書籍「新編 新しい数学1」7章 データを活用して判断しよう 3節 ことがらの起こりやすさ p.242〜245／第9時）の
**多数回の試行によって得られる確率**を体験するための自作ツールです。単一の `index.html` だけで動きます（外部ライブラリなし）。

## 中身（2つのタブ）
1. **① 光子すごろく** … 宇宙のガスの雲を進む光の粒（光子）を、3マスのすごろくに単純化。
   真ん中から観測者側向きに出発し、さいころの 1〜4 でそのまま1マス、5・6 で散乱（向きを反対にしてから1マス）。
   雲の外に出るまでを1回の試行として、観測者側に出た相対度数を記録する。〔展開・まとめ〕
   - **「🎲 1手ずつ」「▶ 1回ふやす」「10回ふやす」**：経路のアニメーション（出た目→散乱→向き→1マス進む）。記録は ○（観測者側）／×（反対側）。
   - **「合計100回まで」「合計1000回まで」「合計1万回まで」「合計10万回まで」**：合計がその回数になるまでまとめて試行し、相対度数の折れ線（横軸はふつう／対数）を表示（1万回→10万回と押しても合計は10万回）。
   - **途中の記録**：合計が20・100・1000・1万・10万回に達したときの相対度数を自動で表に残す（ワークシートの表と同じ並び）。
   - **光の種類**：光A（5・6で散乱）／光B（6だけ）／光C（散乱なし）。光ごとに記録を別に持つ。
   - **クラスの結果（先生用）**：各ペアの回数を入れると、ペアごとの相対度数の数直線と、合わせた相対度数の折れ線を表示。「例のクラス（架空）」も入っている。
2. **② 散乱されやすさを変える** … 雲の厚さ（1〜15マス）と、2種類の光の散乱の起こりやすさ（0〜50%）を変えて、
   観測者側に出る割合をくらべる。判定は実際に出た差で行い、差が偶然のゆれと区別しにくいときは「回数をふやそう」と表示する。〔次時・家庭〕

## 使い方
- ファイルをブラウザで開くだけ（ネット接続なしでも動きます）。
- タブレット配布時は、GitHub Pages 等に置いて **QRコード** で配るのが簡単です。
- URL の末尾に `?tab=2` で②から、`?seed=123` で毎回同じ乱数（リハーサル用）になります。

### GitHub Pages で公開する手順（例）
1. GitHub のリポジトリ `math-pedagogy-1` に `photon/` フォルダを作る。
2. この `index.html` を `photon/index.html` として置く（push は林さん本人が行う）。
3. リポジトリの Settings → Pages → Branch を `main` / `root` にして保存。
4. 数分後に `https://momohayashi304.github.io/math-pedagogy-1/photon/` で公開。
5. そのURLのQRコード（`完成版/画像素材/qr_simulator.png`）を、ワークシートやスライドに貼る。

## 調整メモ
- 散乱の目は `index.html` 内の `SCATTER_FACES = {A:[5,6], B:[6], C:[]}` で変更できます。
- 例のクラスの記録は `EXAMPLE_CLASS`（各ペアの観測者側の回数、各20回）です。架空のデータです。
- 目安の線の値は、反転ルール・真ん中スタートの式 P = (1+(s−2)p)/(1+(L−1)p) で計算しています（3マス：光A 3/5、光B 3/4、光C 1）。
- 正しい動作の目安は ±3SD（光A：1万回で 0.600±0.015、10万回で ±0.005）。±2SD の幅だと、正しくても20回に1回は外れます。
- タブ②の散乱の起こりやすさを 50% までにしているのは、反転ルールで 50% を超えると「行ったり来たり」しやすい不自然な設定になり、100% では終わらなくなるためです（散乱したら向きを半々で決める「等方ルール」の散乱確率 q は、反転ルールの p=q/2 と同じ結果になります）。
- 雲をとても厚くすると、散乱が起こる光はどれも 1/2 に近づいていくのは、一直線（1次元）のすごろくならではの性質です（散乱の起こりやすさが小さいと、厚い雲でも 1/2 から遠いことがあります）。研究の結論として使わないでください。
- 最初の向きをさいころで決めると、散乱の起こりやすさによらず 1/2 になり、光の種類の差が出ません。出発は必ず観測者側向きにしています。
- 乱数は既定で `Math.random()`、`?seed=整数` のときは mulberry32 です。スライド12の画面（`画像素材/sim_tab1.png`）は `?seed=1214785` で「合計10万回まで」を押した状態で、途中の記録が 0.450／0.570／0.605／0.603／0.600（ワークシート枠6の記入例と同じ表示）になります。
- 画面撮影・確認用に `window.simAPI` があります：`run(n)`（いまの光の合計が n 回になるまで追加）、`setLight('A'|'B'|'C')`、`setTab(1|2)`、`loadExampleClass()`、`runCompare(n)`（タブ②で2つの光を n 回まで）。ほかに確認用の `step()`、`trials(n)`、`setAxisLog(b)`、`setGuide(b)`、`setCompare(L, vA, vB)`、`state()`。
- 撮り直しと動作確認：`_生成スクリプト/simulator_shots.sh`（sim_tab1.png・sim_tab2.png・QRコード）、`_生成スクリプト/simulator_check.py`（JSエラーの有無と、表示の数値を設計書・`data/` と照合。44項目）。
