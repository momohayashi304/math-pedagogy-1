# 空間ベクトルの内積シミュレータ「自転する星の磁極の角度」

高校2年 数学C（東京書籍「改訂版 数学Ｃ Advanced」第1章 ベクトル 第3節 空間におけるベクトル／第5時）の
**空間ベクトルの内積で、自転する星の磁極を見る角度θを求める**ための自作ツールです。単一の `index.html` だけで動きます。

## 中身（2つのタブ）
1. **① 自転する星と視線** … 竹串（自転軸）のまわりを回る磁極（球面上の点）と、視線を3Dで表示。
   i（自転軸と視線のなす角）、β（自転軸と磁極の軸のなす角）、ψ（自転した角）をスライダーで動かすと、
   星の中心から出る視線 n⃗＝(sin i, 0, cos i) と磁極 m⃗＝(sinβ cosψ, sinβ sinψ, cosβ) の**成分**、**内積**、**θ** が連動して変わる。
   - **「▶ 自転（アニメーション）」**で星が回り（北極側から見て反時計回り）、θ が周期的に変わる様子を見られる（家庭学習）。
   - ψ＝0°, 90°, 180°, 270° のボタンと、「答え合わせ」をオンにしたときの**厳密値の表示**（例：n⃗・m⃗＝1/2）で、ワークシートの問題1の表を確かめられる（家庭学習）。
   - **観測者の見え方**の小窓で、θ＞90° のとき磁極が星の向こう側に回ることを確かめられる。
2. **② θ のグラフ** … 一般式 cosθ＝cos i cosβ＋sin i sinβ cosψ のグラフ（横軸 ψ、縦軸 θ または cosθ）。
   **最小 |i−β|（ψ＝0°）**、**最大 i＋β（ψ＝180°）**、**ψ＝90°、270° の値 cos i cosβ** と、**θ が 90° を超える時間の割合**を表示する。〔授業のまとめでスライドの静止図で見た一般式とグラフを、家庭で確かめる〕

## 使い方
- ファイルをブラウザで開くだけ（Three.js は cdnjs から読み込みます。ネット接続が必要）。
- 授業中には使いません。生徒は授業後に **QRコード** から開けます（GitHub Pages に置いて配布）。電子黒板に映すときは、ブラウザの拡大 125〜150% が見やすい。
- URL パラメータ：`?tab=2`（タブ②で開く）、`?i=45&b=60`、`?psi=180`、`?ans=1`（厳密値を表示）、`?y=cos`、`?x=time`、`?play=1`。
- ψ は北極側から見て反時計回り（x 軸 → y 軸の向き）に増えます（「▶ 自転」も同じ向き）。

### GitHub Pages で公開する手順（例）
1. GitHub のリポジトリ `math-pedagogy-1` に `vector/` フォルダを作る。
2. この `index.html` を `vector/index.html` として置く。
3. リポジトリの Settings → Pages → Branch を `main` / `root` にして保存。
4. 数分後に `https://momohayashi304.github.io/math-pedagogy-1/vector/` で公開。
5. そのURLのQRコード（`完成版/画像素材/qr_simulator.png`）をワークシートやスライドに貼る。

## 調整メモ
- モデル：cosθ＝n⃗・m⃗＝cos i cosβ＋sin i sinβ cosψ（いちばん単純なモデル）。θ の最小は |i−β|、最大は i＋β。
- 磁極の判定・円弧・道筋は半径1の球面上の点で行う（まち針の頭の半径1.25では θ＞126.9° まで隠れない）。
- θ＞90° の割合の表示は閉じた式 1−arccos(−cot i cotβ)/180°（数え上げは検算用）。
- なす角が 0.5° 未満の円弧は描かない／179.5° 超は垂直な軸で回す／i＜1° では観測者カメラの up を x 軸に／i または β が 0 のときは「θ は一定」。
- 厳密値の表 `EXACT_DOT`（n⃗・m⃗）・`EXACT_M`（m⃗ の成分）は `data/practice_combos.csv`・`data/table_i45_b45.csv` から作ったもの（キーは度）。
- 星のプリセットは `PRESETS`、文献の値（先生用）は `LIT`（出典：`data/literature_i_beta.json` のうち原典で確かめた4件〔`checked_in_original: true`〕）。
- 時間モードの周期は `P_MIN = 185.655`（0.128927103 日。AM Her〔白色矮星がもう1つの星とまわり合う連星〕の周期。白色矮星は約3.09時間で1回自転し、自転と公転は同期。Schwope et al. 2020, A&A 642, A134）。
- アニメーションの速さは `SPIN_SEC`（1回転の秒数、初期 8）。
- 位相 φ で表す発展版のモードは 2026-09-16 に外した（度だけ）。
- 数値は `_生成スクリプト/01_授業データの生成.py`・`02_設計書用の追加計算.py` の出力と一致することを確認済み。
- 作り直し：`index.html` は `_生成スクリプト/シミュレータ_template.html` に data/ の値を埋め込んで `_生成スクリプト/シミュレータ_生成.py` が書き出す（直接編集せず、テンプレートを直して再生成）。撮影と数値の照合は `_生成スクリプト/シミュレータ_撮影と検証.py`。
