# 間隔の相対度数シミュレータ「点の間隔をくらべよう」

中学1年 数学（東京書籍「新編 新しい数学1」第7章 データの活用 p.231〜233／第3時）の
**度数の合計がちがう2つのデータを相対度数でくらべる**ための自作ツールです。単一の `index.html` だけで動きます。

## 中身（2つのタブ）
1. **① 3本の点列クイズ** … ア（線の上のどこにでも、でたらめに置いた点）・イ（目盛りの近くに置いた点）・
   ウ（？）の3本の点の並びから「でたらめに置いたのはどれ？」を予想し、答え合わせをする。〔導入〕
   - 点の数を 20〜200 に変えられる（点が多いときは40ずつに折り返して表示）。
   - 「間隔を色で見る」で、間隔 Δ が 0.5 未満のところを赤で表示（「個数も表示」で個数も）。
   - 「アをもう一度でたらめに置く」で、seed つき乱数で別のでたらめな並びを作れる。
2. **② ヒストグラムと相対度数** … データ（授業の60個・40個、999個までのデータ）、度数の合計、階級の幅、
   度数⇔相対度数、ヒストグラム⇔折れ線、2つを重ねる、累積相対度数、〇未満の割合、度数分布表。〔展開〕
   - おまけ：研究で使う曲線（ランダム行列の近似曲線）を重ねる。

## 使い方
- ファイルをブラウザで開くだけ（外部ライブラリなし。ネット接続は不要）。
- 授業では教師が電子黒板で操作します。生徒には、GitHub Pages 等に置いて **QRコード** で配り、家庭で確かめてもらいます。

### GitHub Pages で公開する手順（例）
1. リポジトリ `math-pedagogy-1` の `spacing/` フォルダに `index.html` を置く。
2. Settings → Pages → Branch を `main` / `root` にして保存。
3. 数分後に `https://momohayashi304.github.io/math-pedagogy-1/spacing/` で公開。
4. そのURLのQRコード（`_共通/tools/make_qr.py`）をワークシートやスライドに貼る。

## 授業での位置づけ
- 導入(5分)：タブ①を電子黒板で。予想 → 答え合わせ → 点の数を増やす。
- 展開(27分)：タブ②を電子黒板で。相対度数の折れ線を重ね、0.5未満の割合（累積相対度数）を読む。999個ずつでも確かめる。
- まとめ(8分)：ウの正体（研究紹介）。家庭ではQRで再確認。

## データについて
- ウ：リーマンゼータ関数の非自明零点 1/2+iγ_n（n=1〜1000）を mpmath の `zetazero` で計算し、
  N(T)=T/(2π)·log(T/(2πe))+7/8 で平均間隔1にそろえた（unfolding）。公開の表は使っていない。
  授業の60個は n=940〜1000 の間隔（クイズのウを点の数200にしたときの右はしの60個と同じ）。
- ア：一様乱数（numpy default_rng、seed 固定）を並べ替えて平均間隔1にそろえた。クイズのアの先頭40個の間隔は授業の40個（seed 3）と同じ。
  イ：整数の位置に ±0.15 の一様なゆらぎ。
- 生成：`../_生成スクリプト/01_零点の計算.py` → `02_授業データの生成.py`（→ `data/spacing_sim_data.json` を埋め込み）。
- GUE の曲線は Wigner surmise による近似式。厳密な GUE との差は小さい（0.5未満で 0.112 と約 0.113）。
  n≤1000 の低い零点では、間隔の小さいところが曲線より少なく出る。

## 調整メモ
- 点列・間隔のデータは `index.html` 内の `DATA`（`spacing_sim_data.json` と同じ形）。
- 階級の幅・しきい値の初期値は `DEFAULTS`（binWidth: 0.25, threshold: 0.5, quizSize: 40）。階級の幅の選択肢は `BIN_WIDTHS`（3.00 を割り切る値だけ）。
- 点の半径と折り返しの規則は `DOT_RULE`（ppu<5 で40単位ずつ折り返し、r=min(5, 0.3·ppu)）。
- 「アをもう一度」の seed の始まりは `RESEED_START`（101）。
- `index.html` は `../_生成スクリプト/08_シミュレータ_生成.py` が、本体 `シミュレータ_本体.html` に `data/spacing_sim_data.json` を埋め込んで作る（直すときは本体を直して再実行）。動作確認・数値照合・撮影は `08_シミュレータ_確認.py`。
